Question: 1 Based on the Agile SDLC model, explain when testing should begin in the sprint cycle, define two entry criteria and two exit criteria you would propose for a sprint, and describe how testing in an Agile model fundamentally differs from testing in the Waterfall model.

ANSWER:
In an Agile model testing should start early in the sprint, as soon as a feature is developed and is ready for testing. Testing continues along with development throughout the sprint.

Entry Criteria:

1. The requirements are clear.
2. The build is ready and can be tested.

Exit Criteria:

1. All planned test cases are executed.
2. Important defects are fixed and the application is working as expected.

Agile vs Waterfall:
- In Agile, development and testing happen together in every sprint.
- In Waterfall, testing usually starts after the development phase is completed.
- Agile allows quick feedback and changes, while Waterfall follows a fixed sequence of phases.

Question: 2 Identify three non-functional testing types that are critical for this payment gateway scenario and justify why each cannot be skipped. Then apply the relevant principle from the 7 Key Principles of Testing that explains why attempting to test every possible transaction combination is not feasible.

ANSWER:
1. Performance Testing
It checks whether the payment gateway can work properly when many users use it at the same time.
Why important: It should handle 5,000 transactions without becoming slow or crashing.

2. Security Testing
It checks whether payment and customer information is safe.
Why important: It protects users from data theft and unauthorized access.

3. Reliability Testing
It checks whether the payment gateway works correctly without frequent failures.
Why important: Customers should be able to make payments successfully.

Testing Principle:
Testing every possible transaction is not possible because there are too many combinations.
