4.
Identify 4 types of errors or issues that static testing (reviewing documents or code without execution) can catch in a test case document for an online movie booking system (like BookMyShow).

Answer:
Static Testing – Movie Booking Test Case

Static testing means checking documents or test cases without running the application.

4 issues we can find:
Missing Steps – Some steps are not written.
Wrong Information – Wrong movie name, date, or price is given.
Unclear Steps – Steps are difficult to understand.
Missing Result – Expected result is not mentioned.
